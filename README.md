# SauceDemo Test Automation Framework

A modular, scalable test automation framework built to validate functional workflows on the SauceDemo e-commerce platform.

## 🛠️ Technology Stack & Framework Architecture
* **Language:** Java
* **Testing Framework:** TestNG (Suite configurations managed via `testng.xml`)
* **Design Pattern:** Page Object Model (POM) for clean separation of UI locators and test scripts
* **Version Control:** Git & GitHub

## 📂 Core Features
* Implemented reusable Page Objects to ensure easy code maintenance.
* Built automated validation flows for user login, product catalog navigation, cart additions, and the checkout funnel.
* Designed modular TestNG configurations to run test scenarios efficiently.
